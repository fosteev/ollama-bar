# Дизайн интерфейса — снимок

Выгрузка проекта Claude Design, по которому сделан текущий интерфейс.

| Файл | Что это |
|---|---|
| `Ollama Bar.dc.html` | сам макет: логика приоритета, восемь состояний панели, элемент меню-бара, окна вывода/истории/настроек, типографика и отступы |
| `support.js` | рантайм канваса Claude Design, сгенерированный; нужен только для просмотра макета |
| `github.md` | карта соответствия экранов файлам репозитория, как её видит Claude Design |

Источник: `claude.ai/design/p/6010e6ec-ad02-4872-92b8-19db997414cc`.

## Как посмотреть

```bash
open "design/Ollama Bar.dc.html"
```

**Нужен интернет.** `support.js` подтягивает React, ReactDOM и Babel с `unpkg.com`, поэтому
полностью офлайн макет не откроется. Сами файлы макета при этом самодостаточны — вся вёрстка
лежит инлайном в HTML, и её можно читать как текст, если рендер недоступен.

## Картинки для README

Иллюстрации в корневом README — рендер этого макета, а не снимки приложения; в самом README это
оговорено. Пересобрать после повторной выгрузки:

```bash
swift scripts/render-design.swift   # → docs/images/*.png
```

Скрипт снимает фреймы через WKWebView (браузер и сеть не нужны, вёрстка инлайновая), выбрасывает
подписи и заметки макета и подставляет английские. Русский текст внутри самой картинки переводится
по словарю в скрипте — если после новой выгрузки в кадре окажется непереведённая строка, рендер
упадёт с её текстом, а не молча уедет в README.
